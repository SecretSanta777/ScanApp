# ScanApp 📱

Приложение для сканирования штрих-кодов и QR-кодов с интеграцией Open Food Facts API.

## 🚀 Функциональность

- **Сканирование штрих-кодов** (EAN-13, EAN-8, UPC-E, Code 39, Code 128)
- **Сканирование QR-кодов**
- **Автоматический запрос к Open Food Facts API** для товарных штрих-кодов
- **Локальное сохранение** отсканированных кодов в Core Data
- **Просмотр истории** сканирований
- **Детальная информация** о каждом сканировании
- **Поделиться** информацией о сканировании

## 🏗️ Архитектура

### Структура проекта

### Технологии
- **SwiftUI** - UI фреймворк
- **AVFoundation** - работа с камерой и сканирование кодов
- **Core Data** - локальное хранилище
- **URLSession** - сетевые запросы
- **MVVM** - архитектурный паттерн

### Основные компоненты

#### MainViewModel
- Управление сессией камеры (AVCaptureSession)
- Обработка разрешений
- Делегат сканирования кодов (AVCaptureMetadataOutputObjectsDelegate)
- Сетевые запросы к API

#### DataBaseManager
- CRUD операции с Core Data
- Раздельное хранение штрих-кодов и QR-кодов
- Проверка на дубликаты

#### NetworkManager
- Запросы к Open Food Facts API
- Обработка ошибок
- Декодирование JSON ответов

## 📱 Использование

1. **Запустите приложение**
2. **Нажмите на иконку QR-кода** для активации камеры
3. **Наведите камеру** на штрих-код или QR-код
4. **Автоматическое сохранение** - данные сохраняются автоматически
5. **Перейдите во вкладку "История"** для просмотра всех сканирований
6. **Нажмите на любой элемент** для просмотра деталей
7. **Используйте кнопку "Поделиться"** для отправки информации

- UPC-E

- Code 128

### QR-коды
- Все стандартные QR-коды

## 📊 API интеграция

При сканировании товарных штрих-кодов приложение автоматически делает запрос к [Open Food Facts API](https://world.openfoodfacts.org/api/v0/product/{code}.json) для получения информации о продукте:
- Название продукта
- Бренд
- Состав
- Nutri-Score

## 🗃️ Локальное хранилище

Данные сохраняются в Core Data с двумя основными сущностями:
- **Barcode** - для товарных штрих-кодов
- **QrCode** - для QR-кодов

## 🔄 Жизненный цикл сканирования

1. Пользователь активирует камеру
2. Система распознает код
3. Определяется тип кода (QR или штрих-код)
4. Для штрих-кодов - запрос к API
5. Сохранение в Core Data
6. Обновление UI
